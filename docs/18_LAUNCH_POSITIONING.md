# 18 — Launch Positioning

## Category

Open AI media command desk.

## Short pitch

OpenMediaForge is a local-first creative studio for AI media production. It helps creators organize references, run provider jobs, manage their own keys, repair outputs, and keep receipts for every generated asset.

## Why now

AI media creators are moving across many tools. Generation is powerful, but production is messy. OpenMediaForge gives creators the missing operating layer.

## Not this

- not another credit wrapper
- not a closed model host
- not a fake all-in-one generator
- not a chatbot
- not a prompt library

## This

- project workspace
- asset/reference map
- provider adapter layer
- job queue
- BYOK authority
- receipts/provenance
- exportable packets

## Audience hooks

### Influencer creators

Keep every reference, prompt, result, and provider run in one studio.

### Video artists

Build coherent shot systems instead of scattered one-off generations.

### Local model users

Connect your own engines without giving up project structure.

### Agencies

Track cost, provider, input, output, and usage history for every asset.

## Honest MVP language

OpenMediaForge starts with a mock provider and local project system. Real providers are added through adapters. The app does not pretend to supply hosted compute before it exists.
