# 00 — Executive Brief

## Product

**OpenMediaForge** is a local-first AI media command desk for creators who make images, videos, music visuals, short-form content, character-consistent scenes, and experimental AI art across many tools.

It solves the coordination problem: assets, prompts, references, providers, keys, costs, jobs, repairs, receipts, and exports.

## Why this exists

AI media generation is no longer one tool. A serious creator might use local ComfyUI, a hosted image model, a video model, a lip-sync service, a prompt compiler, a DAW, a video editor, and a folder of references. The pain is no longer simply "make a picture." The pain is keeping the whole production coherent.

OpenMediaForge is the studio layer above the models.

## Development order

1. Build the open media studio first.
2. Make BYOK its trusted access layer through KeyRail.
3. Spin BYOK out later only after the need is obvious.

## Product position

Not a reseller gateway.
Not a single-provider wrapper.
Not a chatbot.
Not a fake local app.

OpenMediaForge is a creator-owned media workstation that can run mock, local, BYOK, and future hosted compute through clear provider adapters.

## MVP promise

A user can:

1. Create a project.
2. Add references and labels.
3. Choose a provider/model.
4. Submit a generation job.
5. Watch progress.
6. See the output asset.
7. Inspect a receipt.
8. Export the project packet.

The first MVP does this with a Mock Provider so the product can be built, tested, demoed, and verified without compute.

## Audience

- influencer creators
- AI video artists
- Suno/Grok/Sora-style creative tool users
- music-video makers
- short-form social editors
- artists using references and prompt packs

## Strategic moat

The moat is not a list of models. The moat is the production grammar:

- asset maps
- reference budgets
- model manifests
- provider adapters
- job queue
- repair loops
- generation receipts
- cost transparency
- local-first trust
- BYOK authority
- exportable project packets

## What v1 must feel like

A real app. High-end, sharp, useful, and durable. Something a serious creator would keep open all day.
