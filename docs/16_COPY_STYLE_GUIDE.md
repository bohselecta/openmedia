# 16 — Copy Style Guide

## Voice

Sharp, calm, useful. Founder-grade. No hype fog.

## Product words

Use:

- Studio
- Forge
- Project
- Asset Map
- Reference Budget
- Provider
- Model
- Job
- Receipt
- KeyRail
- Credential Ref
- Execution Ticket
- Local mode
- Mock Provider
- BYOK

Avoid:

- magic
- effortless everything
- unlimited
- unfiltered
- no guardrails
- revolutionary
- one-click miracle
- AI slop phrases

Secondary:

## Studio empty states

### No project

> Start with a project. OpenMediaForge keeps prompts, assets, jobs, and receipts together so your work survives beyond one generation.

### No provider

> Mock Provider is ready. Add local or BYOK providers later when you want real compute.

### No key

> This provider needs a key. KeyRail stores access as a credential reference and logs how it is used.

### No receipts

> Receipts appear after jobs complete. They show what made each output and which provider/model/settings were used.

## Provider placeholder copy

> Adapter planned. No live calls are made yet.

## Browser-dev vault warning

> Browser-dev vault is for early local testing. Production key storage will use desktop keychain or encrypted server vault.

## Receipt copy

> This receipt records the prompt, provider, model, inputs, outputs, cost estimate, and network destination for this job.
