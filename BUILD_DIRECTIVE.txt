Core product:
OpenMediaForge is a local-first, provider-neutral AI media command desk. It gives creators a beautiful studio for planning, generating, repairing, tracking, and proving AI media work. Compute is pluggable. BYOK begins as KeyRail, the trusted access layer inside the app.

MVP must work fully with the Mock Provider and zero API keys.

Hard rules:
- Do not hardcode MuAPI or any single provider gateway.
- Do not add fake integrations.
- Honest placeholders are allowed, but label them clearly.
- Do not store raw keys in jobs or receipts.
- UI must never display raw keys after save.
- Provider adapters must use execution tickets, not raw keys.
- Every completed generation must create a receipt.
- Every result asset must be findable in Library/Assets.
- No product claim may imply OpenMediaForge supplies hosted video compute in MVP.

Verification:
Add and run:
- npm run typecheck
- npm run lint
- npm run build
- npm run verify

The verify script must check:
- Provider registry loads.
- Mock provider exists.
- Sample model manifests load.
- Mock image generation creates a job.
- Mock job completes.
- Receipt is created.
- No string "muapi" exists in source files.
- No hardcoded single-provider API base exists in production source.
- Job and receipt types contain credential references only, not raw secret fields.

Do not claim done until all checks pass and the app can run through this demo:
Create project → add prompt → choose Mock Provider / mock-image-v1 → submit job → watch progress → see output card → open receipt → see provider/model/task/prompt/input/output/cost/network fields.
